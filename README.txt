КАК ЗАПУСКАТЬ ПРОГРАММЫ

1. Откройте терминал в этой папке.
2. Запускайте нужный файл командой:

   python exercise_1.py
   python exercise_2.py
   python exercise_3.py
   python exercise_4.py

Что нужно сделать, чтобы получить результаты как в отчете:

Задание 1
- python exercise_1.py -c  -> результат в консоли.
- python exercise_1.py     -> результат в result_1.txt.

Задание 2
- python exercise_2.py
- команды уже загружаются из resourse_2.txt;
- нажмите кнопку «Расчёт».

Задание 3
- python exercise_3.py
- программа сразу открывается в инженерном режиме;
- видны 5 строк истории, 7 ячеек памяти и функции dms, 10^x, pi, tanh, ln;
- для примера можно ввести 2+3*4 и нажать =, затем проверить pi, tanh или ln.

Задание 4
- python exercise_4.py
- снизу всегда видны «Начало», «Окончание» и четыре поля 70, 20, 54, 12;
- чтобы получить состояние, показанное в отчете, нажмите «Показать» рядом с полем 70.
- окно можно свободно уменьшать и увеличивать; диаграмма перестраивается по размеру окна.

Автоматическая проверка:
   python -m unittest -v test_core.py
